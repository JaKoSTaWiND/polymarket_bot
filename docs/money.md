# Как в боте хранятся деньги и позиции

## Единицы хранения

Бот хранит деньги и количество токенов целыми числами с масштабом 1 000 000.
В Go для этого используется `int64`, в базе данных — `BIGINT`.
У каждой величины есть своя единица измерения.

| Величина | Что означает | Пример хранения |
| --- | --- | --- |
| Денежная сумма | Миллионные доли pUSD | 15 pUSD → `15_000_000` |
| Количество токенов | Миллионные доли токена конкретного исхода | 7,5 токена YES → `7_500_000` |
| Лимитная цена | Миллионные доли pUSD за один токен | 0,37 pUSD за токен → `370_000` |

## Баланс, ордера и позиции

- Денежный баланс показывает, сколько pUSD у кошелька. Для новых ордеров доступен баланс за вычетом зарезервированных денег.
- При выставлении ордера на покупку бот резервирует деньги с учётом применимой комиссии. При выставлении ордера на продажу он резервирует токены выбранного исхода.
- При каждом исполнении бот обновляет деньги, количество токенов и резерв по фактическим суммам сделки. Каждое исполнение учитывается один раз. При отмене ордера освобождается оставшийся резерв.
- Позиция ведётся отдельно для каждого кошелька и токена исхода. Например, токены YES и NO одного рынка образуют две позиции.
- Для открытой позиции учитываются количество оставшихся токенов и их себестоимость в pUSD. Текущая оценка позиции равна количеству токенов, умноженному на текущую цену. Изменение цены влияет только на оценку.

## Преобразование и округление

- Если API передаёт сумму в миллионных долях, бот читает её как целое число. Если API передаёт сумму в pUSD или количество в целых и дробных токенах, бот умножает значение на 1 000 000 ровно один раз.
- Десятичные значения разбираются без `float64`. Для умножения цены на количество используется точная арифметика с промежуточным результатом достаточной разрядности.
- При формировании ордера соблюдаются шаг цены рынка и допустимая точность количества. При показе суммы пользователю её можно округлить до центов. В учёте сохраняется полная точность.

## Пример покупки

На кошельке 15 pUSD. Пользователь покупает 7,5 токена YES по 0,37 pUSD без комиссии.
Стоимость покупки равна 7,5 × 0,37 = 2,775 pUSD. После полного исполнения ордера:

- денежный остаток — 12,225 pUSD, в хранилище `12_225_000`;
- количество токенов YES — 7,5, в хранилище `7_500_000`;
- себестоимость позиции — 2,775 pUSD, в хранилище `2_775_000`.

Если цена вырастет до 0,40 pUSD, оценка позиции составит 3 pUSD. Денежный остаток сохранится на уровне 12,225 pUSD.
